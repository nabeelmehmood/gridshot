# Gridshot is now FPS Dojo

This browser aim trainer was renamed to **FPS Dojo** and moved.

- Play: https://nabeelmehmood.github.io/fpsdojo/
- Code: https://github.com/nabeelmehmood/fpsdojo

## What this repo is for

It only keeps the old address, https://nabeelmehmood.github.io/gridshot/, working. Its `gh-pages`
branch holds a small redirect site that forwards every old page, including `?mode=` links and the
mode pages, to the same page on FPS Dojo, and clears the old service worker for returning players.

The redirect site is built and published from the FPS Dojo repo with `npm run deploy:redirect`
(see "Old address" in its README). Don't delete, rename or archive this repo, and keep it public:
old links, bookmarks and search results all go through it.

The game's history up to the rename is in the FPS Dojo repo.
